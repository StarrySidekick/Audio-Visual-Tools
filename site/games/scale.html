Modes in one idea

A mode is a scale defined by its pattern of whole steps (W) and half steps (H). The seven classic modes all use the same pattern as the major scale, just starting from a different note. C major played from D to D is D Dorian.

The fastest way to tell them apart is to compare each one to plain major or natural minor and listen for the one note that differs. That is what the hints after each answer point at. "Always C" keeps the root fixed so only that note changes between questions.
